# sweet-home の運用メモ

お家（sweet-home）の日常と、止め方・譲り方のまとめ。正本はこのファイル。

## 1日のリズム

| 時刻 | すること |
|---|---|
| 9:30 | 朝当番（日替わり）。天気（気象庁・東京）入りの挨拶を、話す動画（10秒）で |
| 10:30 / 12:30 / 14:30 | リビングの会話。見出し行のあと、発言ごとに約3分の間。夕方からは実験・vlog など「作る・見る」時間 |
| 20:00 | 夜当番（朝とは別の子）。話す動画（10秒） |
| 21:30 | その日の日記（#日記 と、サイトの /diary へはルナが運ぶ） |

- 朝当番は昨日の日記の「種」を受け取る。当番の台詞は70文字目安。
- 雨の日は当番が傘の一言を添える。
- 日記には「いまの話」（前提／今日の進み／残っている問い）が付く。

## 話題の循環

- 日記の材料は、その日の本当の出来事（当番・リビングの会話・共有）だけ。
- 日記は「明日の種」を残す（途中で終わった話＋本人の言葉そのまま）。翌日の朝当番とリビングが受け取る。
- 朝当番のあと（〜10:30まで）に #リビング や #vlog へ動画やリンクが共有されたら、その日のリビングはそれを話題にする。
- 夕方のリビングは、今日の話題と関係のある過去の日記の話題があれば、そちらに戻ることがある。

## 実験モード（お家を止める）

るるが自分の実験をするときは、お家は手放す。方法は3つ、どれでも同じスイッチ。

1. **Discord で言う** — #作業場 に「止めて」と書く（再開は「再開して」）。
   お家が1分以内に拾って、#作業場 に「止めたよ」と返す。
2. **ルナに言う** — チャットで「止めといて」と言えば、ルナが #作業場 経由で止める。
3. **ファイルで** — sweet-home のフォルダで `touch out/PAUSE`（再開は `rm out/PAUSE`）。

効き方:

- 判定は各ジョブの開始時刻ちょうど。生成の最中に止めても、その1本は止まらない。
- 止まっている間に時刻が来たジョブは、その日は手放す（完了扱い）。
  再開した途端に一気に取り戻すことはしない。
- 例: 11時に止めて13時に再開 → 12:30のリビングだけ休み、14:30からは普通に動く。

## GPU の約束（お家は居候）

- 動画を入れる前、ComfyUI のキューに他のジョブがあれば、空くまで待つ。
- 重いジョブ（当番動画）のあとは10分空けてから次の生成へ。
- 当番・リビング・日記の生成が終わるたび、Ollama のモデルを VRAM から解放する。
- 熱ガード: 85℃ 以上では、落とせる重いジョブだけ落とす（当番は守る）。

## 再起動と巻き戻し

- コンテナを再起動しても、済んだジョブは再実行しない（`out/state-<日付>.json`）。
- ジョブは「開始した」時点で記録される（2026-11-26〜）。途中で落ちたり再起動しても、そのジョブはその日は最初からやり直さない。
- ジョブは自分の時刻の枠（既定30分、`JOB_GRACE_MINUTES`）を過ぎたら、追いつき実行せず「手放す」。再起動後は、次の枠から一日が続く（2026-11-26 の教訓：17:30 のリビングが再起動のたびに再実行され、執行役を約20分ずつ塞いで全体を止めた）。
