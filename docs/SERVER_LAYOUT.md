# 新サーバーの設計 (2026-11-23 決定)

## 決定
- 切り替えは **サーバーごと新しく** する。旧サーバー (Starlight Factory) は
  旧ボットを止めて「足跡」として残す。旧 #lunachannel も旧チャンネルと同じ扱い
  (読み返せる記録、投稿はしない)
- 理由: 引き継ぐと比較対象になりがちだから。新チャンネルだけ作っても
  旧投稿が同じサーバー内に並び、基準線が残ってしまう
- 新サーバーは **将来、誰かを招待することを前提** に設計する
  (最初から見せる場所と暮らす場所を分ける)

## チャンネル叩き台
### 入口 (招待した人が最初に見る)
- #ようこそ — この場所の説明と約束ごと。日記への案内
### 暮らし (姉妹が暮らす。招待した人は読める、書くのは姉妹と るる)
- #当番 — 朝・夜の挨拶
- #リビング — 会話の塊はここ (旧 #lunachannel の後継。名前も新しくする)
- #vlog — ゆる Vlog
- #日記 — 夜の日記 (サイトにも同じものが載る)
### 作業 (招待した人には見せない)
- #作業場 — ログ・エラー・テスト投稿

## 引き継ぐもの / 引き継がないもの
- 引き継ぐ: 日記・人格・出来事の蓄積 (全部データ側にある)
- 引き継がない: サーバーの構造、RSS 時代のチャンネル編成、旧投稿との並び
- 切り替え時にやること: 読み取り用ボット「ルナ」を新サーバーへ招待し直す
