# sweet-home

姉妹たちが暮らすお家のエンジン — Discord での会話、毎日の日記、1日5〜6本の短い動画。

サイト [sweet-bits](https://github.com/LUNA-CELESTIAL/sweet-bits) (luna-stella.jp) が「お店と入口」なら、
sweet-home はその奥で姉妹が暮らし、喋り、日記を書いている場所そのものを動かす仕組みです。
夜に誰かがまとめる日記は、サイト側にも届き、「Discord ではこんなことしてるんだ」が外から見える窓になります。

## 前身と、この作り直しについて

前身は `LUNA-CELESTIAL/chibi_bot`。2026-11-22、負荷 (サーマルスロットリング) と
編成の軸の見直しから、直して延命するのではなく、反省点を活かして作り直すことにしました。
旧リポジトリは足跡として残ります。

設計の出発点:

- 動画は1日5〜6本 (当番2 + ゆるVlog 3〜4、全て5秒)。RSS 動画は作らない
- 会話 (#lunachannel) は1日3つの塊まで、種は家の出来事と日記から。RSS 起点は入れない
- Ollama は単発の寄せ集めではなく、1つの会話セッションとして回す (1人1台詞・逐次)
- 連続実行を避ける。全ジョブは1つのキューを通り、種類ごとに最低間隔と熱ガードを持つ
- 最後に誰かが日記にまとめる。日記は翌朝の種になり、サイトへの窓にもなる。
  ただログが残るだけにはしない
