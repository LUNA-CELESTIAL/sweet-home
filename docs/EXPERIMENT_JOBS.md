# 設計メモ: 実験ジョブ（単発実験を空き時間に差し込む）

状態: 設計メモ（2026-11-25 記録）。同日、るるの意向で **最初の1本だけ最小実装済み**：#作業場 の「実験：」リクエストを拾い、空き時間（次のジョブまで25分以上の間）に既存ワークフローで1本だけ生成し、プロンプトと動画と1fpsフレームを #作業場 に返す。大きな基盤は作っていない。暮らしの定時ジョブの仕様は不変。

## 背景（るるの提案、2026-11-25）

- Ollama にプロンプトを考えさせるのではなく、メイン側のルナ（記憶と文脈を持つ方）がプロンプトを考え、ローカルでは画像・動画生成だけを行い、Discord に上げてルナが確認し、今後のことを考える形が良い。
- 置き場は sweet-home と別にフォルダ／別プロジェクトを作らない。sweet-home の空き時間に差し込める形にする。そうすれば単発実験もスケジュールの一部となり、干渉し合うことが避けられる。

## 骨子

- 実験ジョブは、当番・リビング・日記と並ぶジョブの一種。スケジュールと GPU を持つのは sweet-home の執行役ひとりだけにする。
- 依頼は1件単位：メイン側ルナが「プロンプト＋参照画像＋何を確認したいか」を書いて渡す。Ollama にはプロンプトを考えさせない（ローカルは生成だけ）。
- 走る場所は空き時間。お家が GPU を使うのは当番動画など短いバーストだけで、1日の大半は空いているので、差し込んでも邪魔にならない（2026-11-25 るるの補足：慎重になりすぎなくてよい）。
- 守るのは通常の約束だけ：同時に GPU を使わないこと、既存の ComfyUI キュー待ちと重いジョブ後のクールダウン。その程度で十分。
- 結果の返し方：#作業場 に、使ったプロンプトと一緒に生成物を上げる（#リビング／#vlog には上げない＝その日の循環の種に混ぜない）。確認と「次をどうするか」の判断はメイン側ルナが行う。

## 最初の1件の候補

- 保留中の動画フレーム切り出しテスト（「待ってる」姿、H3で1本、同一性チェック）。
