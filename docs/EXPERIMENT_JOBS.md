# 設計メモ: 実験ジョブ（単発実験を空き時間に差し込む）

状態: 設計メモ（2026-11-25 記録）。同日、るるの意向で **最初の1本だけ最小実装済み**：#作業場 の「実験：」リクエストを拾い、空き時間（次のジョブまで25分以上の間）に既存ワークフローで1本だけ生成し、プロンプトと動画と1fpsフレームを #作業場 に返す。大きな基盤は作っていない。暮らしの定時ジョブの仕様は不変。

## 背景（るるの提案、2026-11-25）

- Ollama にプロンプトを考えさせるのではなく、メイン側のルナ（記憶と文脈を持つ方）がプロンプトを考え、ローカルでは画像・動画生成だけを行い、Discord に上げてルナが確認し、今後のことを考える形が良い。
- 置き場は sweet-home と別にフォルダ／別プロジェクトを作らない。sweet-home の空き時間に差し込める形にする。そうすれば単発実験もスケジュールの一部となり、干渉し合うことが避けられる。

## 骨子

- 実験ジョブは、当番・リビング・日記と並ぶジョブの一種。スケジュールと GPU を持つのは sweet-home の執行役ひとりだけにする。
- 依頼は1件単位：メイン側ルナが「プロンプト＋参照画像＋何を確認したいか」を書いて渡す。Ollama にはプロンプトを考えさせない（ローカルは生成だけ）。
- 走る場所は空き時間。お家が GPU を使うのは当番動画など短いバーストだけで、1日の大半は空いているので、差し込んでも邪魔にならない（2026-11-25 るるの補足：慎重になりすぎなくてよい）。
- 守るのは通常の約束だけ：同時に GPU を使わないこと、既存の ComfyUI キュー待ちと重いジョブ後のクールダウン。その程度で十分。
- 結果の返し方：#作業場 に、使ったプロンプトと一緒に生成物を上げる（#リビング／#vlog には上げない＝その日の循環の種に混ぜない）。確認と「次をどうするか」の判断はメイン側ルナが行う。

## 画像実験（ピクセル i2i 仕様 v1、2026-11-26 追加）

静止画の実験は「画像実験：」リクエストで同じ経路に乗る。仕様は調査チャットでルナ分が確立した「ピクセル i2i 標準仕様 v1」（正本: ~/workspace/pixel-art-test/SPEC.md）で、実装は src/pixel.py（同一性タグ表＋ワークフロー構築）と src/experiment.py の分岐。対象メンバーの錨の絵（deformer_<id>.png）とタグは家側が持ち、依頼は「対象」と任意の denoise・追加タグだけを指定する。結果の PNG は #作業場 にタグ付きで返る。チェックポイント／LoRA 名は PIXEL_CKPT_NAME / PIXEL_LORA_NAME で上書き可（既定は仕様の名前）。

## 衣装実験（全身イラスト i2i、2026-11-28 追加）

衣装の着せ替え検証は「衣装実験：」リクエストで同じ経路に乗る。ピクセル仕様は錨の衣装ごと残す設計で目的が逆なので、別レーンにする（実装は src/costume.py と src/experiment.py の分岐）。ピクセル LoRA なし・トリガータグなし、ステップ25／CFG 6、ネガティブ空、seed は家の慣例で固定。同一性タグは「衣装を除いた本人」で家側が持ち（現在はルナのみ）、衣装の圧縮プロンプトは依頼側が「衣装：」の後に付ける（複数行可）。錨は等身大版の fullbody_<id>.png（デフォルメ錨とは別に input へ置く。ちび錨でのパイロットでは衣装の面積が足りず、0.6では替わらず0.75では顔が先に壊れたため）。結果の PNG は #作業場 にタグ付きで返る。denoise は着替え幅の測定対象（パイロットは No.16 で 0.6／0.75／0.9）。衣装候補と判定の記録は ~/workspace/cyberpunk-costume-test-list.md。

## 週間テーマ（2026-11-28 追加、実験ではなくトークテーマの配達）

ルナが1週間分のリビングのテーマを用意して #作業場 に投稿する。同じ見張りが受け取り、`out/topic-queue.json` にしまう。生成は走らない。受理すると見張りが件数を #作業場 に返す。

```
週間テーマ：
2026-11-29｜ルナ｜待つ時間｜蕾が開くまでみたいに、結果が出る前の時間をどう過ごすか
2026-11-30｜スピカ｜測ってみたい小さなこと｜家の中で、まだ数えたことのないものを数えてみる
```

- 1行1件: `日付｜言い出しの名前｜テーマ｜切り口`（切り口は省略可）。解釈できない行は飛ばす。
- 消費は日付キー: その日の分だけがその日のリビングに使われ、他の日に回らない。
- 優先順位: 朝の共有 ＞ 日記の種（新しく開いた話題のみ）＞ 週間テーマ ＞ 関連する過去話題。週間テーマは天井ではなく床。
- 用意したテーマには本人の原文引用が無い。パケットは「今週のテーマとして持ち寄られた話題」と明記し、言い出しの子が自分の言葉で開く。引用の偽装はしない。
