# sweet-home の運用メモ

お家（sweet-home）の日常と、止め方・譲り方のまとめ。正本はこのファイル。

## 1日のリズム

| 時刻 | すること |
|---|---|
| 7:00 | 朝当番（日替わり）。天気（気象庁・東京）入りの挨拶を、話す動画（10秒）で |
| 10:30 / 14:30 / 17:30 | リビングの会話。見出し行のあと、発言ごとに約3分の間 |
| 21:00 | 夜当番（朝とは別の子）。話す動画（10秒） |
| 21:30 | その日の日記（#日記 と、サイトの /diary へはルナが運ぶ） |

- 朝当番は昨日の日記の「種」を受け取る。当番の台詞は70文字目安。
- 雨の日は当番が傘の一言を添える。
- 日記には「いまの話」（前提／今日の進み／残っている問い）が付く。

## 実験モード（お家を止める）

るるが自分の実験をするときは、お家は手放す。方法は3つ、どれでも同じスイッチ。

1. **Discord で言う** — #作業場 に「止めて」と書く（再開は「再開して」）。
   お家が1分以内に拾って、#作業場 に「止めたよ」と返す。
2. **ルナに言う** — チャットで「止めといて」と言えば、ルナが #作業場 経由で止める。
3. **ファイルで** — sweet-home のフォルダで `touch out/PAUSE`（再開は `rm out/PAUSE`）。

効き方:

- 判定は各ジョブの開始時刻ちょうど。生成の最中に止めても、その1本は止まらない。
- 止まっている間に時刻が来たジョブは、その日は手放す（完了扱い）。
  再開した途端に一気に取り戻すことはしない。
- 例: 13時に止めて16時に再開 → 14:30のリビングだけ休み、17:30からは普通に動く。

## GPU の約束（お家は居候）

- 動画を入れる前、ComfyUI のキューに他のジョブがあれば、空くまで待つ。
- 重いジョブ（当番動画）のあとは10分空けてから次の生成へ。
- 当番・リビング・日記の生成が終わるたび、Ollama のモデルを VRAM から解放する。
- 熱ガード: 85℃ 以上では、落とせる重いジョブだけ落とす（当番は守る）。

## 再起動と巻き戻し

- コンテナを再起動しても、済んだジョブは再実行しない（`out/state-<日付>.json`）。
- まだ済んでいないジョブは、時刻を過ぎていれば起動直後に実行される。
