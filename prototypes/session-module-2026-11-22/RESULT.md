# 会話セッションモジュール (offline) 結果

コード: `src/llm.py` / `src/session.py`、検証: `sim/simulate_session.py` (FakeLLM)
既存の検証 (scheduler / duty / diary) も全部再実行して通過 (regression OK)。

## 通ったこと (配線の規則)
- 場のパケット (種+原文引用) は1回だけ作られ、全呼び出しに原文どおり届く
- 各呼び出しは自分の人格スライスだけを見る — 他の姉妹の「やりたいこと」が
  プロンプトに混ざらないことを機械的に確認した
- トランスクリプトが累積し、2人目は1人目の実際の発言を見ている
- 終了はルール (指定の4往復)。終わると出来事プールに1行だけ残る
- LLM の境界は generate(prompt) 1本だけ。「会話全体を一括生成する API」は
  意図的に存在しない。実機では OllamaClient (env のモデル名、仮値では起動拒否) に差し替える

## まだ無いもの
- 会話の質そのもの (FakeLLM は台本)。実機の Ollama で初めて検証できる
- 投稿タイミング (2〜10分の実時間の間隔) はスケジューラ側の実行時に付く
