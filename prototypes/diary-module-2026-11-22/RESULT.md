# 日記モジュール (offline) 結果

コード: `src/diary.py`、検証: `sim/simulate_diary.py`
材料: 2026-11-22 の実際の出来事プール (Discord 6話題の引用は原文どおり + 家の出来事1件)。

## 通ったこと
- 時間帯ブロックで最大5節に収まる (この日は 朝/昼/午後/夕方 の4節)
- 固有名詞が原文どおり残る: Pingツール (Wi-Fi への drift なし)、引用も verbatim で入る
- Discord 外の家の出来事 (sweet-home の置き場決定) も同じプールから節に入った
- 種は「途切れたステラの Pingツール」から断片形 (話題+引用+接続の一言、時間の言葉なし) で生成され、
  翌朝の当番 (こはく) の文に「昨日」が1回だけの形で埋め込めた — 日記→当番の循環が部品間で通った
- 書き手は日付ローテーション (この日はルナ)

## まだ無いもの (正直な線引き)
- offline の本文は「〜の話があった」の骨格文だけ。書き手の目・接続の散文は
  実機の Ollama 生成層の仕事で、このモジュールは構造とデータの受け渡しを担う
- siteExcerpt と title の生成も生成層側 (構造側は sections/topics を渡すところまで)
